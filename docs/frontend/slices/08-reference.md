## 4. 수용 기준 확인

2026-10-29, 실제 API 위에서 SCR-08 시험 5개(AC 4개 + 「왜?」 연결 1개) 통과.

| AC | 결과 | 비고 |
|---|---|---|
| SCR-08-AC-1 | 통과(107행은 실제, "색인 없음"은 목) | 11쪽을 넘기며 107행. 실제 데이터에는 "색인 없음"이 없음. 한 문서의 절 수만 0으로 바꾼 응답 → 위 띠 "색인 안 됨 1건", 그 문서가 맨 앞에 "색인 없음" |
| SCR-08-AC-2 | 통과 | 정답지 입력 CSV1-000004의 제품 = HMI-XGT-eXP60, 표에 단가 520·납기 4, 상세 창에 520 USD·4주 |

### 확인하며 알게 된 것

- 시연 DB의 문서 107개는 모두 절이 있다(절 895개). 그래서 "색인 없음"은 실제로는 나오지 않는다.
- 문서 종류는 7개다(DS 23, IG 23, TG 23, RN 13, FAQ 11, MG 10, POL 4). 목업의 "사용자 매뉴얼"은 데이터에 없고, 이름은 기술 명세서 v1.4 §4-1 표를 따랐다.
- 우선순위 규칙 PR-05·PR-07은 긴급도 목록이 비어 있어 "모든 긴급도"로 보인다(조건 원문에 긴급도가 없다).
- 목업을 따른 곳(구현 선택): 탭 → 검색 상자 → 표 10행씩, 문서의 종류 요약 단추와 색인 띠, 우선순위 표 아래 "위에서부터 처음 맞는 행 하나를 씁니다".
- 명세를 따른 곳(목업과 다름): 고치기·올리기·색인 다시 만들기 버튼 없음, 문서 표의 언어·초안 인용·수정일 열 없음(개정·글자 수로), 목업의 "원본 표 ○○.csv" 대신 "원본 테이블 ref.○○", 부서 관리의 미해결·기한 위험 수 없음.
- 문서 절 목록과 제품 상세는 목업의 행 펼침 대신 창으로 연다(표 부품에 펼침 행이 없어서, 구현 선택).
