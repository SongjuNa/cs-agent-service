### 확인하며 알게 된 것

- 해결사례 글은 영어다. 화면에서 번역하지 않는다(design Risks).
- 같은 문의인데 고장 진단(고장 사전)과 비슷한 해결사례가 다른 원인을 보일 수 있다. 예: CSV1-000017 사본은 진단 1순위가 펌웨어 결함(FLT-046), 사례 3건은 모두 단자 풀림이었다. 둘 다 참고용이고 초안에는 쓰지 않는다.
- 에러 코드는 거르지 않고 순서에만 쓴다(design 결정 1). 그래서 "E.OC만" 찾으면 전체 783건이 대상이고, 앞 20건이 E.OC다.
- 이 브랜치 전에 처리한 시연 티켓에는 Q8b 기록이 없어 "비슷한 해결사례" 줄이 나오지 않는다. 다시 처리하거나 새로 접수하면 나온다.
- 백엔드 전체 시험: 364개 통과, 1개 건너뜀, 2개 실패. 실패 둘은 앞 슬라이스부터 흔들리는 Gemini 실시간 시험이다(CSV1-000031을 MANUAL로 분류하는 시험, AC-021-2 실시간 초안 시험).
- 목업을 따른 곳(구현 선택): 안내 띠, 연한 파랑 거르기 상자, 표.
- 명세를 따른 곳(목업과 다름): 검색해야 결과가 나옴, 제외·다시 사용 단추와 참고 횟수·상담원 수정 기록 없음, 사례 번호는 RC-…(원본 번호), 해결 요약은 case_summary, 원래 티켓은 번호만(링크 없음).
