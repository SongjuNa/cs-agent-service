## 4. 수용 기준 확인

2026-10-29, 실제 API 위에서 SCR-07 시험 4개 통과.

| AC | 결과 | 비고 |
|---|---|---|
| SCR-07-AC-1 | 통과 | CSV1-000017 사본을 새로 접수 → CUST-0350 상세에 그 티켓이 원본 번호 CSV1-000017과 함께 보임. 화면 행 수 = 서버 이력 수, 접수 시각 내림차순 |

### 확인하며 알게 된 것

- 고객 등급은 PLATINUM 56, GOLD 155, STANDARD 389로 600명이다. 목업에 있는 SILVER는 고객 테이블(ref.customer)에 없어서 단추가 나오지 않는다.
- 데모 DB의 CUST-0350에는 앞선 시험이 접수한 사본이 많이 쌓여 있다(미해결 22건). 시연 전에 정리할지는 따로 정할 일이다.
- 전화 상담으로 접수한 티켓은 연락처 이메일이 비어 있어, 최근 문의가 전화면 "최근 연락처 이메일"이 "—"로 보인다.
- 목업을 따른 곳(구현 선택): 탭·등급 요약·연한 파랑 거르기 상자·표, 상세의 머리 카드와 숫자 칸 5개.
- 명세를 따른 곳(목업과 다름): 목록에 답장 언어·담당자 이메일 열과 "미해결 문의 있는 고객만" 칸 없음(상세 머리의 "최근 답장 언어"·"최근 연락처 이메일"로), 목록 정렬은 최근 문의 시각 내림차순, 상세 주소는 `/customers/{id}`.
- 아직 못 한 곳: 명세 §차이표의 "나라별 지도 그림 위에 API 숫자를 얹음"과 "미해결 열로 정렬"은 넣지 않았다. 지금 나라별은 표만 있고, 목록 표는 정렬 단추가 없다. AC에는 걸리지 않는다.
