# 화면 명세: SCR-11 문의 배정 관리

- 연결: 최신 목업(Frontend 폴더) `#/admin/assign` "문의 배정 관리". 변경 `add-reassign`(담당 변경 API), `add-assign-admin`(이 화면). 요구사항 번호는 아직 없음(임시 FR-초안-08)
- 팀 합의(2026-10-31): 목업이 최신 기준
- 사용 API: `GET /tickets?dept=&assignee=&alert=&priority=&q=&page=&size=15&as_of=`, `POST /sub-tickets/assign`(머리 `X-Agent-Id`), `GET /ref/agents`, `GET /ref/departments`

## 영역

| 요소 ID | 영역 | 표시 | 계약 칸 |
|---|---|---|---|
| SCR-11-F | 거르기 | 부서(처음은 상단에서 고른 부서) / 담당 상담원(그 부서 명단) / 사유(미해결 전체·기한 초과·기한 임박·우선순위 P1) / 검색(문의 번호, 고객사) / 오른쪽에 "○건". 값은 주소(`dept`, `who`, `kind`, `q`, `page`)에 남는다 | counts.total |
| SCR-11-B | 선택 막대 | 한 줄이라도 고르면 "n건 선택 → 담당을 [고르세요] [재배정]" + [필터된 ○건 모두 선택](거른 건수가 200 이하일 때) + [선택 해제] | POST /sub-tickets/assign |
| SCR-11-T | 표 | 선택 칸 / 문의(번호, 한 줄 요약, 고객사) / 부서 / 우선순위 / 상태 / 사유(경고 칩) / 남은 시간 / **담당 상담원(줄마다 고르는 상자, 바꾸면 바로 반영)**. 줄을 누르면 문의 상세 | rows[] |
| SCR-11-PG | 쪽 넘김 | 쪽당 15건 | page, size |

## 화면 상태

- 부서 미선택: "부서를 선택하세요".
- 로딩: 표 스켈레톤. 읽기 실패: 이전 목록을 흐리게 두고 "목록을 불러오지 못함. 새로고침" 띠.
- 바꾼 뒤: 안내 띠 "n건을 {이름}에게 재배정했습니다 · k건은 바꾸지 못함(사유)". 모두 건너뛰면 빨간 띠 "바뀐 문의가 없습니다 · …".
- 담당 후보는 그 문의를 맡은 부서 명단의 사람만. 다른 부서·종료·이미 그 사람이면 서버가 건너뛰고 사유를 돌려준다.

## 수용 기준

- SCR-11-AC-1: Given 상담원과 부서를 고른 스냅샷, When `/admin/assign`을 열면, Then 그 부서 미해결 문의가 한 쪽 15건 이하로 나오고 "○건"이 서버 counts.total과 같으며 왼쪽 메뉴의 "문의 배정 관리"가 현재 화면으로 표시된다.
- SCR-11-AC-2: Given 같은 화면, When 사유를 "기한 초과"로 바꾸면, Then 건수가 서버(경고 FR_BREACHED·RES_BREACHED)와 같고 주소에 `kind=breach`가 남으며 줄에 "지남" 표시가 있다.
- SCR-11-AC-3: Given 시험용 접수본 한 줄, When 줄의 담당 상담원을 같은 부서의 다른 사람으로 바꾸면, Then "1건을 {이름}에게 재배정했습니다" 띠가 뜨고 서버의 담당이 바뀐다.
- SCR-11-AC-4: Given 여러 줄, When 하나를 고르고 [필터된 ○건 모두 선택]을 누르면 "○건 선택"이 거른 건수와 같고, 줄을 골라 받을 상담원을 정해 [재배정]하면 안내 띠가 뜨고 선택이 풀린다.

## 목업과 다른 곳

| 목업 | 이 화면 | 이유 |
|---|---|---|
| 부서 전체 | 부서 하나씩(처음은 내 부서) | 접수함 API가 부서를 하나 받는다 |
| 사유 4종(기한 초과·임박·P1·이관 장기) | 3종(이관 장기 없음) | "이관 장기"는 서버에 값이 없다 |
| 상담원 전체 목록 | 선택한 부서 명단 | 담당은 그 부서 명단의 사람만(서버 규칙) |
