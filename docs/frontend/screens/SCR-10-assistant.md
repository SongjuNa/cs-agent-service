# 화면 명세: SCR-10 상담원 도우미 (임시 번호)

> 초안(2026-10-30, 변경 add-agent-assistant). 조장 검토 전이다. 목업의 상담원 도우미(ELLO)를 근거 기반 질의응답으로 만든다.

- 연결 요구사항: FR-초안-07(상담원 도우미). 근거 규칙: CLAUDE.md 규칙 2(모델 호출 한 곳, 보내기 전 가리기), 규칙 3(고객 발송에 쓰지 않음), 규칙 4(새 표 없음)
- 기준 목업: 상담원 목업의 오른쪽 아래 도우미 창(레이아웃 기준선: 떠 있는 버튼 → 창 → 말풍선 → 출처 칩)
- 사용 API: `POST /assist/ask`, `GET /chunks/{chunk_id}`(출처 열기)
- 변경 제안서: `openspec/changes/add-agent-assistant/`

## 화면 상태

- 처음: 대화 목록이 비어 안내 글 "오류 코드나 제품 이름을 넣어 물어보세요. 문서에 없는 내용은 찾지 못했다고 답합니다."
- 찾는 중: 보낸 뒤 "찾는 중…" 말풍선. [보내기]는 눌리지 않는다(중복 방지).
- 근거 있는 답: 답 + 출처 칩 + 이어 묻기 칩(+ 주의 글).
- 근거 없음: "찾지 못했습니다." 로 시작하는 답, 출처 칩 없음.
- 모델 실패: 답은 비고 찾은 절의 출처 칩과 주의 글 "답을 만들지 못했습니다. 아래 문서를 직접 확인하세요".
- 검색 실패 또는 색인 없음: "찾지 못했습니다." + 주의 글("검색하지 못했습니다…" 또는 "문서 색인이 아직 없습니다").
- 서버 오류(5xx)·연결 끊김: 말풍선 "답을 가져오지 못했습니다." + [다시 시도].
- 입력 오류(400): 입력 칸 아래에 서버 문구 그대로. 보낸 질문은 입력 칸에 되돌린다.
- 대화 기록: 이 창의 상태에만 있다. 새로고침하거나 [새 대화]를 누르면 사라진다. 서버에 저장하지 않는다.

## 수용 기준 (Given / When / Then)

- SCR-10-AC-1: Given 어느 화면이든, When 오른쪽 아래 "도우미"를 누르면, Then 창이 열리고 안내 띠와 입력 칸이 보인다.
- SCR-10-AC-2: Given 서버가 근거 있는 답(출처 1개)을 주는 상태, When 질문을 보내면, Then 답 말풍선과 `문서 번호 §절 번호` 출처 칩이 보인다.
- SCR-10-AC-3: Given 출처 칩이 있는 답, When 칩을 누르면, Then 그 절 본문이 팝업으로 열린다.
- SCR-10-AC-4: Given 서버가 근거 없음(found=false)을 주는 상태, When 질문을 보내면, Then "찾지 못했습니다."로 시작하는 답이 보이고 출처 칩이 없다.
- SCR-10-AC-5: Given 서버가 오류(500)를 주는 상태, When 질문을 보내면, Then "답을 가져오지 못했습니다."와 [다시 시도]가 보이고, 누르면 같은 질문을 다시 보낸다.
- SCR-10-AC-6: Given 서버가 400 "질문을 입력하세요"를 주는 상태, When 질문을 보내면, Then 입력 칸 아래에 그 문구가 보이고 보낸 글이 입력 칸에 남는다.
- SCR-10-AC-7: Given 이어 묻기 칩이 있는 답, When 칩을 누르면, Then 그 문구를 질문으로 보내고 직전 대화가 함께 간다.
- SCR-10-AC-8: Given 대화가 있는 상태, When [새 대화]를 누르면, Then 대화 목록이 비고 안내 글이 보인다.
