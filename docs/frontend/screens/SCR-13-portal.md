# 화면 명세: SCR-13 고객 포털 미리보기

- 연결: 최신 목업(Frontend 폴더) `#/portal` 고객 포털. 변경 `add-portal-preview`(팀 합의 2026-10-31, 사용자 결정 2026-11-01 "고객 포털 미리보기도"). 요구사항 번호는 아직 없음
- 사용 API: 없음. 시연용 미리보기라 서버에 문의를 만들지 않는다(접수 번호는 예시). 챗봇 답은 규칙으로 만든 예시이고 실제 AI 응답이 아니다
- 주소: `/portal`. 상담원 틀(AppShell) 밖의 화면이다. 왼쪽 메뉴 접수 › 시연 › "고객 포털 미리보기"로 들어가고, 오른쪽 위 "상담원 시스템 (시연용 미리보기)"로 접수함에 돌아간다

## 영역

| 요소 ID | 영역 | 표시 |
|---|---|---|
| SCR-13-T | 머리 | 고객지원 센터, 한국어/English 전환, 상담원 시스템으로 돌아가기 |
| SCR-13-C | 문의 방법 선택 | 두 카드: 챗봇 ELLO(지금 바로 답, 사양·정책·간단한 질문) / 상담원에게 문의(웹 폼, 고장·견적·반품·여러 파일, 최대 72시간). 아래 "챗봇으로 시작해도 상담원에게 남길 수 있어요" |
| SCR-13-F | 웹 폼 | ① 문의 유형 10가지 → ② 유형별 필수 정보(막는 정보는 꼭, 나머지는 "모르겠어요" 가능, 진행 막대) → ③ 문의 내용(10자 이상)·이메일·회사명 → **개인정보 수집·이용 동의 체크박스(필수, 시연 표시일 뿐 저장하지 않음)** → [문의 보내기]. 빠진 필수 항목은 빨갛게 표시하고 개수를 알린다 |
| SCR-13-B | 챗봇 | ELLO와 대화. 공개 문서(정책·데이터시트·설치 가이드·릴리스 노트)만 근거로 답하고 `근거: 문서 §절` 칩을 누르면 발췌가 열린다. 안전 문의·고장·견적 등은 상담원 문의로 접수하는 질문 흐름으로 이어진다. 이메일·전화번호는 가려서 보인다 |
| SCR-13-R | 평가·완료 | 상담 종료 → 해결 여부·별점·의견 → 완료 화면(문의 번호) |

## 수용 기준

- SCR-13-AC-1: Given 접수 메뉴, When 시연 › 고객 포털 미리보기를 누르면, Then 상담원 틀 없이 "무엇을 도와드릴까요?"와 두 방법 카드가 보이고 "상담원 시스템" 링크로 접수함에 돌아간다.
- SCR-13-AC-2: Given 웹 폼에서 유형 "고장"을 고른 상태, When 아무것도 채우지 않고 [문의 보내기]를 누르면, Then "입력하지 않은 필수 항목이 n개"와 개인정보 동의 오류가 보인다. 필수 항목을 모두 채우고 동의하면 "문의를 접수했어요"가 보인다.
- SCR-13-AC-3: Given 챗봇, When "반품 정책이 궁금해요"를 보내면, Then 답과 `근거: POL-RETURN §…` 칩이 보인다.
- SCR-13-AC-4: Given 어느 포털 화면, When English를 누르면, Then 화면 글이 영어로 바뀐다.
