# 화면 명세: SCR-00 공통 틀 (상단 막대, 왼쪽 메뉴, 종 알림)

- 연결 요구사항: D23(로그인 대신 고르기), D33(X-Agent-Id), FR-027(경고), AC-033-8(시연용 상담원)
- 기준 목업: cs-agent-mockup_v1.42.html `updateShell`, `renderProf`, `MENU`, `openBell`, `openSearch` (레이아웃 기준선)
- 화면 정의서: v1 SCR-00, v2 0-3절(M-H-02 상담원 ID)
- 사용 API: `GET /ref/departments`, `GET /ref/agents?dept=`, `GET /me/workload?dept=&as_of=` (종 알림), `GET /tickets?q=` (빠른 검색)

## 화면 상태

- 상담원·부서를 고르지 않음: 접수함·업무 현황은 "상단에서 이름과 부서를 고르세요" 안내만(FR-047 예외 3행). 접수 시뮬레이터·전화 상담은 열린다.
- 부서만 고름: 접수함은 부서 전체, 업무 현황은 "부서 전체 기준".
- 부서·상담원 목록 읽기 실패: 고르기 칸 옆 "목록을 불러오지 못함. 새로고침", 기억해 둔 값은 그대로 쓴다.
- 종 알림 읽기 실패: 점을 숨기고 펼치면 "알림을 불러오지 못함".
- 알림 없음: "새 알림이 없습니다".

|---|---|---|---|

| 상담원 고르기 | — | 이후 모든 요청 머리에 `X-Agent-Id`. 화면 다시 그림 | — |

| 종 누르기 | (이미 읽은 `GET /me/workload`) | 경고 목록 펼침. 펼친 알림은 읽음 처리(브라우저에만) | — |

| 메뉴 누르기 | — | 화면 이동. 명세가 없는 메뉴(공지사항 등)는 목업 화면 | — |

## 입력 검증

- 상담원 ID: 고르기만(자유 입력 없음). 목록에 없는 값이 기억되어 있으면 지우고 다시 고르게 한다.
- 빠른 검색: 앞뒤 공백 제거, 1자 이상일 때만 호출.

## 수용 기준 (Given / When / Then)

- SCR-00-AC-1 (AC-033-8): Given 부서 QA_CLAIM을 고른 상태, When 상담원 목록을 펼치면, Then QA_CLAIM_AGENT_01이 "시연용" 표시와 함께 보인다.
- SCR-00-AC-2: Given 상담원 TS_LV_AGENT_09를 고른 상태, When 아무 쓰기 요청(예: 임시 저장)을 보내면, Then 요청 머리 `X-Agent-Id`가 TS_LV_AGENT_09다.
- SCR-00-AC-3: Given 부서를 고르지 않은 상태, When 접수함을 열면, Then "부서를 선택하세요"만 보이고 목록 요청을 보내지 않는다.
- SCR-00-AC-4: Given 미해결 360건 재생 + 스냅샷 + TS_LV, When 종 알림을 펼치면, Then 1차 응답 경고가 해결 경고보다 위에 있고, CSV1-003951(FR_AT_RISK)이 1차 응답 경고 묶음에 있으며, 목록은 12건 이하다.
- SCR-00-AC-5: Given 새로고침, When 화면을 다시 열면, Then 이전에 고른 부서·상담원·기준 시각이 그대로다.
