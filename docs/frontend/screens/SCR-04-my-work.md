# 화면 명세: SCR-04 나의 업무 현황

- 연결 요구사항: FR-047 (AC-047-1~7), FR-026·027, D31(핵심 사용자 = 1차 상담원)
- 기준 목업: cs-agent-mockup_v1.42.html `viewHome` (레이아웃 기준선: 인사말 → 숫자 타일 4개 → 탭 → 탭별 표)
- 화면 정의서: v1 SCR-04
- 사용 API: `GET /me/workload?dept=&scope=&as_of=` (머리 `X-Agent-Id`)

## 화면 상태

- 로딩: 타일 4개 회색 자리, 표 스켈레톤.
- 이름·부서 미선택: "상단에서 이름과 부서를 고르세요"(API message)만.
- 부서만 선택: 머리 "부서 전체 기준", 숫자는 부서 전체.
- 영역에 대상 없음: 영역별 문구 "승인 대기 초안이 없습니다", "기한 위험·위반 문의가 없습니다", "고객 회신 대기 문의가 없습니다", "이관 회신 대기 문의가 없습니다"(API empty 문구를 그대로), 타일 0.
- 오류: 이전 값을 흐리게 두고 "불러오지 못함. 새로고침".
- 자동 갱신: 5분마다. 탭 선택은 그대로.

## 입력 검증

입력 칸이 없다. 상단 막대의 값만 쓴다(SCR-00).

## 수용 기준 (Given / When / Then)

- SCR-04-AC-1 (AC-047-1): Given 미해결 360건 재생 + 스냅샷 + 부서 TS_LV, When 화면을 열면, Then 기한 위험·위반 표에 해결 AT_RISK 8건, BREACHED 26건, 1차 응답 경고 CSV1-003951이 모두 있다.
- SCR-04-AC-2 (AC-047-2): Given 정보 요청 DRAFT 초안 2건, When 화면을 열면, Then 타일 ①이 2이고 승인 대기 초안 표에 두 줄이 있다.
- SCR-04-AC-3 (AC-047-3): Given CSV1-003578이 정보 요청 뒤 130시간 경과(리마인드 발송됨), When 고객 회신 대기 탭을 보면, Then 그 줄에 "리마인드 발송됨"과 경과 130h가 보인다.
- SCR-04-AC-4 (AC-047-4): Given CSV1-000017이 FIELD_SVC로 이관됨, 부서 TS_LV, When 이관 회신 대기 탭을 보면, Then 그 줄에 이관 부서 FIELD_SVC와 이관 시각이 보인다.
- SCR-04-AC-5 (AC-047-5): Given 오늘 이 상담원이 답변 1건 발송, 이관 1건, When 화면을 열면, Then 오늘 처리한 건수가 발송 1, 이관 1이다.
- SCR-04-AC-6 (AC-047-6): Given 어느 표의 한 행, When 누르면, Then 그 티켓 상세가 열린다.
- SCR-04-AC-7 (AC-047-7): Given 우선순위 조정으로 경고가 새로 생긴 문의, When 다음 갱신 뒤 보면, Then 기한 위험·위반 표에 나타난다.
- SCR-04-AC-8: Given 이름·부서를 고르지 않은 상태, When 화면을 열면, Then "상단에서 이름과 부서를 고르세요"만 보인다.
