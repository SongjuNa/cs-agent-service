# 화면 명세: SCR-09 접수 이력 (해결사례 검색) (임시 번호)

- 연결 요구사항: FR-초안-06(해결사례 직접 검색), FR-019(같은 색인), D30(팀 정답지 사례 제외), 설계 원칙 5(상담원 참고용)
- 기준 목업: cs-agent-mockup_v1.42.html `viewSimilar` (레이아웃 기준선: 안내 띠 → 요약 → 필터 → 표)
- 화면 정의서: 없음
- 사용 API (아직 없음, 변경 add-case-search): `GET /cases?q=&error_code=&product_code=&category_code=`, `GET /cases/{case_id}`

## 화면 상태

- 처음: 검색 칸만. "증상, 에러 코드, 제품 중 하나 이상을 넣어 찾으세요".
- 검색 중: [찾기] 꺼짐 + 진행 표시.
- 결과 없음: "조건에 맞는 사례가 없습니다".
- 입력 없음: "검색어를 입력하세요"(400).
- 뜻 검색 실패: N-09-04 띠와 함께 거르기 결과.
- 오류: "검색하지 못함. 다시 시도".

## 입력 검증

- 네 칸 중 하나 이상 필수: "검색어를 입력하세요".
- 검색어는 200자 이하(구현 선택). 서버가 보내기 전에 가린다(CLAUDE.md 규칙 2).

## 수용 기준 (Given / When / Then)

- SCR-09-AC-1 (FR-초안-06 AC 초안): Given 에러 코드 E.OC만 넣은 상태, When [찾기]를 누르면, Then 같은 에러 코드 사례가 먼저 보이고 팀 정답지 문의의 사례가 없다.
- SCR-09-AC-2: Given 네 칸이 모두 빈 상태, When [찾기]를 누르면, Then "검색어를 입력하세요"가 보인다.
- SCR-09-AC-3: Given 결과 표의 한 행, When 누르면, Then 원인·조치·결과가 있는 사례 상세가 보인다.
