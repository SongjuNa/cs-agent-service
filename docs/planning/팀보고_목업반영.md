### 자동 발송 안전장치
- 항상 사람이 확인: 고장·설치·반품·보증·견적·주문 유형, P1·P2, 안전·설비 정지, 복합 문의, 막는 정보 누락, 근거 없음. 설정으로 풀 수 없고 서버가 400으로 거부
- 상담원 [승인하고 발송]과 같은 확인(`send_issues`)이 비어 있고 검증(L8)을 통과한 초안만 발송
- 스위치 하나로 끔(`/admin/auto`). 오류가 나도 접수 처리는 성공하고 초안이 남음
- **한계:** 이 시스템은 실제 메일을 보내지 않음. "발송"은 기록. 메일을 연동하기 전에 `AUTO_SEND_DEFAULT=false`로 둘 것

접수함(선택·내보내기·내 차례·검토 모드·자동 처리 탭), 문의 상세 2단 화면(지금 할 일, 초안 강조, 내부 메모, 사후 검수), 나의 업무 현황(내 실적, AI 자동 처리), 문의 배정·담당 변경, 한국어 요약 한 줄, 이관 메일 표시, 운영 대시보드, 자동 처리 규칙 화면, 상담원 도우미.

## 3. DB 변경 (이미 만든 DB에 적용 필요)

신규 DB는 `docs/database/schema.sql`로 충분합니다. 기존 DB는 아래를 `svc`(필요하면 `scoring`도)에 적용하세요. 데이터는 지워지지 않습니다.

```sql
ALTER TABLE svc.sub_ticket ADD COLUMN IF NOT EXISTS summary_ko text;
ALTER TABLE svc.ticket_message ADD COLUMN IF NOT EXISTS via_mail boolean NOT NULL DEFAULT false;
ALTER TABLE svc.ticket ADD COLUMN IF NOT EXISTS body_ko text;  -- 고객 원문 한국어 번역(add-body-translation)
CREATE TABLE IF NOT EXISTS svc.internal_note (
  note_id bigserial PRIMARY KEY, ticket_id text NOT NULL REFERENCES svc.ticket (ticket_id),
  body text NOT NULL CHECK (char_length(btrim(body)) BETWEEN 1 AND 2000),
  author text NOT NULL, created_at_utc timestamptz NOT NULL DEFAULT now());
CREATE INDEX IF NOT EXISTS internal_note_ticket ON svc.internal_note (ticket_id, created_at_utc);
CREATE TABLE IF NOT EXISTS svc.assignment_history (
  assign_id bigserial PRIMARY KEY, sub_ticket_id text NOT NULL REFERENCES svc.sub_ticket (sub_ticket_id),
  from_assignee text, to_assignee text NOT NULL, changed_by text NOT NULL,
  changed_at_utc timestamptz NOT NULL DEFAULT now(), CHECK (from_assignee IS DISTINCT FROM to_assignee));
CREATE INDEX IF NOT EXISTS assignment_history_sub ON svc.assignment_history (sub_ticket_id, changed_at_utc);
CREATE TABLE IF NOT EXISTS svc.auto_setting (key text PRIMARY KEY, value jsonb NOT NULL, updated_by text NOT NULL, updated_at_utc timestamptz NOT NULL DEFAULT now());
CREATE TABLE IF NOT EXISTS svc.auto_review (message_id bigint PRIMARY KEY REFERENCES svc.ticket_message (message_id), reviewed_by text NOT NULL, reviewed_at_utc timestamptz NOT NULL DEFAULT now());
-- ticket_message_kind_combo: DROP CONSTRAINT 후 schema.sql의 새 정의로 ADD (자동 발송 절 추가)
```

**고객 원문 번역(add-body-translation):** 새 열 `svc.ticket.body_ko`, 새 호출 L12(`prompts/l12_translate_v1.md`), 새 API `POST /tickets/{id}/translate`. 상담원이 [번역 보기]를 눌렀을 때만 번역하고 저장하며, 번역문은 참고용이라 고객 발송·초안·다른 모델 호출에 쓰지 않습니다.

받은 뒤 `docker compose up -d --build api`, 접수 이력이 필요하면 `python -m jobs.replay_history`(12개월치 3,635건)와 `jobs.replay_demo`를 실행하세요.
