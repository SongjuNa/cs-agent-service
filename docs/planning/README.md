# planning — 프로젝트 기획

## 목적
프로젝트가 **왜 필요한지, 무엇을 언제까지 누구와 만들지**에 대한 확정된 기준을 관리합니다.

## 관리 대상
- `project-plan.md` — 프로젝트 기획서의 Markdown 원본(확정 후 추가)
- 필요 시 배경 분석 근거 및 확정 범위에 대한 참조 링크

## 포함할 내용
추진 배경, 문제 정의, 목표·성공 지표, 사용자, MVP·확장·제외 범위, 주요 구성 개요, 일정/WBS 요약, 담당 역할, 위험 및 대응. 기능별 상세 구현 명세는 중복 작성하지 않습니다.

## 작성·검토
- 기존 Notion 기획서 v1.1이 현재 원본이라면 **먼저 팀에서 원본 위치를 확정**합니다. Git으로 이전하기 전까지 Markdown 파일을 독립적으로 수정하지 않습니다.
- Git을 원본으로 채택하면 `project-plan.md`만 직접 편집하고 HTML/PDF는 이 파일에서 생성합니다.
- 제출 시점의 HTML/PDF는 GitHub Release 등으로 보존할 수 있습니다.
- 문서 버전은 본문 메타데이터와 커밋/태그로 관리하며 `v1.x/` 복제 폴더는 만들지 않습니다.
- 기획 범위를 수정할 때에는 [requirements](../requirements/README.md)와 [OpenSpec](../../openspec/README.md)에 미치는 영향을 확인합니다.
