# database — 데이터 모델 및 ERD

## 목적
고객 문의, 처리 이력 등 프로젝트의 **데이터 모델·관계·제약조건**을 텍스트로 관리합니다.

## 원본 형식
- `schema.dbml` — ERD를 위한 **DBML 편집 원본**(스키마 합의 후 추가)
- 다이어그램 PNG/SVG/PDF는 필요 시 이 원본에서 생성한 결과물로 관리합니다.

## 작성 규칙
- 테이블·컬럼·관계, PK/FK, 필수 여부, 유니크 제약 등을 명시합니다.
- 데이터 형식과 이름은 프로젝트 용어·요구사항에 맞춥니다.
- [dbdiagram.io](https://dbdiagram.io) 같은 DBML 지원 도구로 시각화할 수 있습니다.
- 실제 구현이 시작되면 ORM 모델 및 마이그레이션이 **실행 스키마의 기준**이 될 수 있으므로 DBML과 차이가 없는지 PR에서 확인합니다.
- 확정 전 예시 테이블을 실제 데이터 모델처럼 생성하지 않습니다. 민감한 실제 데이터를 ERD 파일에 기록하지 않습니다.

## 버전 관리
`schema.dbml` 하나를 계속 수정하고, 변경 과정은 Git 이력으로 관리합니다. 버전별 디렉터리는 만들지 않습니다.
