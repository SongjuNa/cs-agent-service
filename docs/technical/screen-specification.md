## 0. 공통

### 0-1. 1순위 최소판이 하는 일과 하지 않는 일

| 한다 (1순위 기능) | 하지 않는다 (2순위 이후) |
|---|---|
| 근거 영역: 시스템 판단값과 근거 한 줄씩, "왜?", 인용 절 본문·조회값 출처(FR-024) | 판단값 직접 수정(유형·긴급도·제공 항목, FR-030), 우선순위 조정(FR-028), 이관(FR-033), 고객 회신 입력(FR-032) |
| 초안 + 대역 보기, 대역 다시 만들기(FR-039) | 상태 배지, SLA 두 시계와 경고(FR-025~027) |
| 검토 표시 5개, [다시 검증](FR-024 처리 6, FR-049) | 고장 진단 후보(FR-018), 이관 후보(FR-020) — 3순위 |
| [임시 저장], [승인·발송]과 발송 전 확인(FR-031) | 발송 뒤 상태 전이와 SLA 다시 계산(FR-031 처리 4·6) |
| 발송 기록(SENT 행)과 1차 응답 시각 기록(FR-031 처리 3·5) | 복합 문의 여러 구역(FR-006·022) — 1순위는 하위 문의 항상 1개 |

### 0-2. 들어오는 길

접수함(FR-029)이 2순위이므로, 1순위에서는 주소 `/tickets/{ticket_id}`로 바로 연다. 문의는 `jobs/run_tickets.py`가 `POST /tickets`로 넣는다(프로젝트 구조 1순위). 화면 맨 위에 문의 번호 입력 칸을 하나 둔다(M-H-01).

### 0-3. 상담원 식별

공통 상단 막대(SCR-00)가 2순위라서 최소판 머리에 **상담원 ID 입력 칸**(M-H-02)을 둔다. 브라우저에 기억하고 모든 요청 머리 `X-Agent-Id`에 싣는다. 발송 행의 보낸 사람(ticket_message.sent_by_name)에 들어간다(D23, T43). 비어 있으면 [승인·발송]이 꺼진다.

### 0-7. 레이아웃 — A안 사이드바형 (라-21, 2026-10-22 조장 결정)

목업 안A(bootcamp/mockup/화면목업_3안_2026-10-20/안A_사이드바형.html)의 틀을 쓴다: 왼쪽 사이드바(LS Blue `#0A1E5A`) + 위 머리 막대 + 가운데 작업 영역. 문의 상세는 요약 머리 아래 **탭 4개**(고객이 보낸 것 / 시스템이 판단한 것 / 보낼 것 / 이력)이고 기본 탭은 "보낼 것"이다.

1순위 최소판에서는 이렇게 쓴다.

| A안 자리 | 1순위 최소판 |
|---|---|
| 왼쪽 사이드바 | 메뉴 "문의 상세" 하나만 켠다. 접수 시뮬레이터·접수함·나의 업무 현황은 흐리게 두고 "2순위"라고 적는다. 접기 가능 |
| 위 머리 막대 | 상담원 ID 입력 칸(M-H-02)과 문의 번호 입력 칸(M-H-01). 부서·기준 시각 고르기는 2순위 |
| 요약 머리 | H-01, H-03, H-04. 상태·우선순위·기한 요약 칩 중 상태·기한은 2순위라 빼고, 우선순위 칩만 둔다 |
| 탭 "보낼 것"(기본) | R 영역 전부 |
| 탭 "시스템이 판단한 것" | C 근거 영역 전부 |
| 탭 "고객이 보낸 것", "이력" | 흐리게 두고 "2순위". 누를 수 없다 |

검토 표시 줄(R-01)에서 걸린 번호를 누르면 "시스템이 판단한 것" 탭으로 옮겨 그 줄을 펼친다(① → C-10, ② → C-07, ③ → C-10, ④ → C-02). ⑤는 탭을 옮기지 않고 "보낼 것" 탭의 지적 문장으로 옮겨 간다.
