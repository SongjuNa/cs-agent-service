# design — 산출물 디자인 가이드

## 목적
프로젝트 기획서 HTML, 발표자료, 요구사항 명세서 등 **산출물의 시각적 일관성**을 유지합니다.

## 관리 대상
- `design-guidelines.md` — LS전선 CI Manual에 근거한 적용 원칙(검증된 자료 반영 시 추가)
- `design-tokens.css` — HTML 문서용 공통 색상·폰트·간격 변수(제작 시작 시 추가)
- 승인된 로고·다이어그램 자산은 사용 권한 확인 후에만 등록

## 구분 원칙
- **CI 공식:** 로고, 보호 여백, 색상, 시그니처 및 공식 그래픽 사용 규칙
- **프로젝트 권장:** 문서용 Pretendard 등 대체 서체, 중립색, 표/카드 및 PDF 출력 규칙
- 프로젝트 권장 값을 LS전선 공식 CI 규칙이라고 표시하지 않습니다.

## 초기 디자인 방향
- LS Blue `#0A1E5A`, LS Red `#FA002D` 중심의 기업형 기술 보고서
- 흰색 본문, 절제된 레드 강조, 정돈된 표와 다이어그램
- HTML에서 A4 PDF로 출력 시 깨짐·표 잘림·한글 렌더링 확인
- 로고는 임의 재제작하지 않고 승인된 원본을 사용

**CI Manual 전체 및 로고 사용 허가를 대체하지 않습니다.** 세부 수치는 실제 공식 자료와 대조 후 확정합니다.
