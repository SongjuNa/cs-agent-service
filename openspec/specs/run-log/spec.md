# run-log Specification

## Purpose
처리 흐름 실행과 단계마다 입력·출력·시간·오류·언어 모델 사용량을 남기고 조회한다(명세서 v1.5 FR-036, 기술 명세서 v1.4 §6-5).

## Requirements

### Requirement: 실행·단계 기록 (FR-036)
처리 흐름 실행마다 run 한 행과 단계마다 step 한 행을 남겨야 하고, 단계 행에는 시작·끝 시각, 소요(ms), 결과, 가린 입력·출력 요약, 오류 종류, 지시문 버전, 입력·출력 토큰, 호출 수를 넣어야 한다(MUST)(근거: FR-036 처리 1·2, 기술 명세서 §6-5, §3-5). 지시문·응답 전문은 `LOG_FULL_LLM_IO`가 켜졌을 때만 가려서 남겨야 한다(MUST)(근거: FR-036 처리 4). 다시 처리는 새 run으로 남기고 이전 run은 지우지 않아야 한다(MUST)(근거: FR-036 처리 5).

#### Scenario: AC-036-1 접수 실행의 단계
- **GIVEN** CSV1-000004를 접수
- **WHEN** 실행 로그를 본다
- **THEN** run 1개에 T2부터 초안·검증까지의 step이 순서대로 모두 SUCCESS이고, 숫자 조회(Q9) 출력에 list_price_usd 520과 std_lead_time_weeks 4가 있다

#### Scenario: AC-036-2 분류 입력에 제목 없음
- **GIVEN** 분류 단계(T2)의 입력 기록
- **WHEN** 항목 이름 목록을 본다
- **THEN** inquiry_subject가 없다

#### Scenario: AC-036-3 시간 초과와 다시 처리
- **GIVEN** 분류 호출(L1)이 두 번 시간 초과되는 상태
- **WHEN** 접수한다
- **THEN** run 결과 FAILED, 마지막 단계 T2, 그 step의 오류 종류 LLM_TIMEOUT이고, 다시 처리(RETRY)하면 새 run이 생기고 이전 run은 남아 있다

#### Scenario: 시간과 사용량
- **GIVEN** 토큰 수를 돌려주는 언어 모델 연결로 접수
- **WHEN** 단계 행을 본다
- **THEN** 언어 모델을 부른 단계마다 호출 수·토큰·지시문 버전이 있고, 처리 흐름 노드가 낸 단계(T6 상태 전이 제외)마다 시작·끝 시각과 소요가 있다

#### Scenario: 전문 저장 설정
- **GIVEN** LOG_FULL_LLM_IO가 꺼진 상태와 켜진 상태
- **WHEN** 접수한다
- **THEN** 꺼지면 전문이 없고, 켜지면 가린 전문이 단계 출력에 있다

### Requirement: 실행 기록 조회 (FR-036)
티켓의 실행 목록과 실행의 단계 목록을 조회할 수 있어야 하고, 티켓 상세 "왜?"는 그 줄을 만든 단계를 가리켜야 한다(MUST)(근거: FR-036 처리 7, 기술 명세서 §8-1).

#### Scenario: AC-036-5 우선순위 "왜?"에서 단계로
- **GIVEN** 티켓 상세의 우선순위 줄
- **WHEN** why의 단계를 연다
- **THEN** 우선순위 단계(Q3)의 출력에 priority_rule_id와 적용 조건(priority_trace)이 있다

### Requirement: 실패·중단·보존 (FR-036)
로그 저장이 실패해도 처리 결과 저장은 계속해야 하고, 끝나지 않은 실행은 서버가 켜질 때 FAILED로 닫아야 하며, 90일이 지난 실행은 매일 지워야 한다(MUST)(근거: FR-036 예외 1~3행, 기술 명세서 §6-5, 지울 수 없는 실행은 C-83).

#### Scenario: 로그 저장 실패
- **GIVEN** 단계 한 행의 저장이 실패하는 상태
- **WHEN** 접수 결과를 저장한다
- **THEN** 처리 결과는 저장되고 실패는 서버 로그에 남는다

#### Scenario: 끝나지 않은 실행
- **GIVEN** 결과가 비어 있는 실행
- **WHEN** 서버가 켜진다
- **THEN** 그 실행은 FAILED로 닫히고 하위 문의에 "UNKNOWN: 처리 중단(서버 재시작)"이 남는다

#### Scenario: 보존 기간
- **GIVEN** 90일이 지난 실행
- **WHEN** 매일 보존 작업이 돈다
- **THEN** 자체 검사(self_check)나 상담원 피드백(agent_feedback)이 가리키지 않는 실행과 그 단계는 지워지고, 메시지 이력과 가리키는 실행은 남는다
