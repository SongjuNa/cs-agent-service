## ADDED Requirements

### Requirement: 상담원이 해결사례를 직접 찾는다 (FR-초안-06)
상담원은 검색어·에러 코드·제품·유형으로 해결사례를 찾을 수 있어야 하고, 같은 에러 코드 사례가 먼저 나와야 한다(MUST). 팀 정답지 문의의 사례는 결과와 상세에 없어야 하고, 결과는 초안 입력에 쓰지 않아야 한다(MUST).

#### Scenario: 에러 코드 검색
- **GIVEN** FR-019 색인을 만든 상태
- **WHEN** 에러 코드 E.OC로 찾는다
- **THEN** 앞쪽 결과가 모두 E.OC 사례이고 팀 정답지 문의의 사례는 없다

#### Scenario: 입력 없음
- **GIVEN** 검색 칸이 모두 빈 상태
- **WHEN** 찾는다
- **THEN** 400 "검색어를 입력하세요"가 온다

#### Scenario: 정답지 사례 상세
- **GIVEN** 팀 정답지 문의에서 나온 사례 ID
- **WHEN** 상세를 요청한다
- **THEN** 404가 온다
