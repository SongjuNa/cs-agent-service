# Proposal: 고객 포털 미리보기를 최신 목업대로 (add-portal-preview)

## Why
왼쪽 메뉴 "고객 포털 미리보기"가 "목업 화면으로만 두는 메뉴입니다" 안내뿐이다. 최신 목업(`#/portal`)에는 방법 선택·웹 폼·챗봇 ELLO·평가가 있고, 팀 화면 검토(2026-11-01)에서 웹 폼에 개인정보 동의 체크박스를 넣자는 의견이 나왔다. 팀 합의(목업이 최신 기준)와 사용자 결정(2026-11-01)에 따라 구현한다.

## What Changes
화면만 만든다. 서버·API·DB 변경 없음(규칙 4 해당 없음).
- `/portal` 화면(상담원 틀 밖): 한국어/English, 두 방법 카드, 웹 폼(유형 10가지 → 유형별 필수 정보 → 내용·이메일 → **개인정보 동의 체크박스(필수, 저장 안 함)**), 챗봇 ELLO, 평가·완료.
- 챗봇은 목업과 같은 규칙 기반이다(고객에게는 공개 문서만, 고장·견적 등은 상담원 문의 접수 흐름). 제품 23종과 공개 문서(정책·데이터시트·설치 가이드·릴리스 노트·유지보수)를 목업 데이터에서 뽑아 포털 폴더에 두었다.
- 접수 번호는 예시다. 서버에 문의를 만들지 않는다(웹 폼 접수에는 고객 번호가 필요한데 포털에는 고객 식별이 없다). 화면 아래에 시연용이라고 적는다.
- 챗봇 관리처럼 눌러도 안내뿐이던 항목은 이미 메뉴에서 뺐다.

## 규칙 3·4 관련
- 규칙 3(고객 발송 금지): 이 화면은 고객이 보는 모양일 뿐 고객에게 아무것도 보내지 않고, 저장도 하지 않는다.

## 하지 않는 것
- 실제 문의 접수(서버 연결)와 실제 AI 챗봇 답. 실제 시스템에서는 서버 API가 필요하다.
