# Proposal: 왼쪽 메뉴 구성을 최신 목업에 맞춤 (add-menu-structure)

## Why
목업은 위 탭마다 왼쪽 메뉴가 다르다(홈 = 나의 업무 현황, 접수 = 접수함 + 시연 "고객 포털 미리보기"). 저장소는 홈 탭을 눌러도 접수 탭이 켜지고, 접수 메뉴 하나에 7개 항목이 섞여 있다(2026-11-01 나란히 비교).

## What Changes
- 화면만 바꾼다. 서버·API·DB 변경 없음.
- 홈 탭 = "나의 업무 현황"만. 공지사항·시스템 알림(목업 화면으로만 두던 항목)은 목업에 없어 메뉴에서 뺀다.
- 접수 탭 = 접수함, 소제목 "시연" 아래 "고객 포털 미리보기", 소제목 "상담 도구" 아래 전화 상담·접수 이력·고객 관리·챗봇 관리(목업에 없는 기존 화면이라 없애지 않고 아래로 모은다).
- 경로 표시줄의 "접수" 링크는 접수함으로 간다.

## 하지 않는 것
- 고객 포털 미리보기 화면 자체(별도 변경), 지식 관리 화면(별도 변경).
