# Proposal: 나의 업무 현황 모양을 최신 목업에 맞춤 (add-home-look)

## Why
2026-11-01 목업과 나란히 비교한 결과 나의 업무 현황의 숫자 칸·목록·오른쪽 열 모양이 달랐다. 화면만 바꾼다(서버·API·DB 변경 없음).

## What Changes
- 머리: 상담원·부서 알약, "09.30 기준" 칩.
- 숫자 칸: 카드형 5장(새 문의 · 승인 대기 초안 · 기한 위험·위반 · 고객 회신 대기 · 이관 회신 대기), "n 건" 표기.
- "지금 처리할 건": 우선순위 배지, 문의 번호·고객사, 요약, 다음 행동, 가장 급한 경고 1개와 남은 시간.
- 오른쪽 열: 진한 남색 "가장 급한 내 문의"(큰 남은 시간), "AI 자동 처리"(항상 표시, 사후 검수 대기 칩), "새로 온 건"(내 담당 NEW 4건, 접수함 API).

## 하지 않은 것
- 아래 탭 표(기한 위험·위반 / 승인 대기 초안 / 고객 회신 대기 / 이관 회신 대기)와 오늘 처리·내 실적은 그대로 둔다. 목업은 이 정보를 작은 카드 둘로 줄여 보이지만, 저장소는 표가 상세 목록 역할을 하고 시험이 의존한다.
- 목업의 "1차 응답 아직 안 보낸 건" 카드: 서버에 같은 기준의 목록이 없다.

## 시험
SCR-04·SCR-12 14개 중 12개 통과. 실패 2개(SCR-04-AC-1·3)는 고정 시연 데이터 부재로 변경 전에도 실패하는 기준선.
