# Proposal: "기한" 라벨에 1차 응답 기한과 해결 기한을 구분해 보임 (add-sla-labels)

## Why
팀 화면 검토(2026-11-01): 접수함·나의 업무 현황에서 "기한 지남"과 "5일 3시간 초과" 같은 값이 나란히 있어 어느 SLA(1차 응답 기한 / 해결 기한)인지 알 수 없다.

## What Changes
화면 글자만 바꾼다. 서버·API·DB 변경 없음.
- 접수함·문의 배정 관리 표: "남은 시간" → "해결 기한까지", "기한 · 경고" → "경고 (1차 응답·해결 기한)". 칩은 이미 "1차 응답 지남"·"해결 기한 임박"처럼 종류를 적는다.
- 나의 업무 현황 "지금 처리할 건"·"가장 급한 내 문의": 시간 값 앞에 "해결 기한"을 붙인다. 위험·위반 표 머리글도 "해결 기한까지".
