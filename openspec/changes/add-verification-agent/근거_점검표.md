# 근거 점검표: add-verification-agent

점검은 두 겹으로 했다. 하나는 `scripts/check_sources.py`이고, 다른 하나는 초안을 쓰지 않은 독립 검증자다.

## 1. 스크립트 결과
- 없는 이름·번호: 0건.
- "근거:" 표시가 없는 줄: 1건(시험 목록 줄, 경고만).

## 2. 독립 검증자 결과 (고치기 전)
약 84문장을 판정했다. 근거 있음·뜻 같음 67, 뜻이 다름 11, 근거 표시 틀림 4, 근거 없음 2.

데이터 대조 결과는 다음과 같다.
- CSV1-000004: language fr, QUOTE, 참고 문서 POL-ORDER, 정답 답변 끝 "Validité 30 jours.".
- POL-ORDER §5: "Quotations are valid for 30 days. Volume discounts apply to larger quantities."
- GS-076의 원래 ticket_id는 문서 어디에도 없다(design 설명과 같음).
- eval.self_check: VERIFY 행은 message_id 필수.

## 4. 남은 "사람 확인 필요" → 개발_결정_기록 C 항목
