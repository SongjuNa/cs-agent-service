# Proposal: 접수함 모양을 최신 목업에 맞춤 (add-inbox-look)

## Why
2026-11-01 목업과 나란히 비교한 결과 접수함 열 구성과 필터 배치가 목업과 달랐다(열이 화면 밖으로 밀림). 팀 합의(목업이 기준)로 모양을 맞춘다. 화면만 바꾼다.

## What Changes
열을 9개로 정리(No. / 문의 번호 / 문의 요약 / 고객사 / 우선순위 / 처리 상태·다음 행동 / 남은 시간 / 기한·경고 / 접수 시각), 요약 탭 정리, 탭 줄 오른쪽 도구, 검색 줄 칩, 상세 필터 접기. 서버·API·DB 변경 없음. 자세한 것은 SCR-02 명세 끝의 "화면 모양 맞춤".

## 시험
SCR-02 시험의 열 이름을 새 구성에 맞춰 고침(AC-2·3·10). AC-3은 고정 시연 데이터 부재로 변경 전에도 실패(기준선).
