# Proposal: 운영 현황·문의 배정 관리·자동 처리 규칙 모양을 최신 목업에 맞춤 (add-ops-pages-look)

## Why
최신 목업과 나란히 보면(2026-11-01) 대시보드 세 화면의 이름·머리·표 표기가 다르다.

## What Changes
화면만 바꾼다. 서버·API·DB 변경 없음.
- 운영 대시보드 → **운영 현황**(메뉴·제목·경로). 머리 오른쪽에 "관리자 · 전체 부서". 설명 줄은 마우스 올림 글로. 숫자 카드는 목업처럼 5개("고쳐 보낸 비율" 카드는 값이 비어 있어 뺌).
- 문의 배정 관리: 설명 줄 대신 오른쪽 "담당 상담원 변경" 표시, 사유는 가장 급한 칩 하나(+N), 해결 기한까지는 색 칩("21일 8시간 초과").
- 자동 처리 규칙: 설명 줄을 스위치 카드 안으로.
- 왼쪽 메뉴 대시보드 하위 항목(문의 배정 관리·자동 처리 규칙)에 아이콘.

## 하지 않는 것
- 일별 접수 추이의 기간 선택(30일·90일·1년)은 목업에 없지만 기능이라 유지한다. 도넛의 "챗봇 해결"은 챗봇 데이터가 없어 넣지 않는다. 채널 이름(채팅·포털)은 실제 데이터 이름을 쓴다.
