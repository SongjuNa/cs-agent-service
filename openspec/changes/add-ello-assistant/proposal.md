# Proposal: 상담원 도우미를 ELLO 캐릭터로, 비슷한 해결사례 블록 제거 (add-ello-assistant)

## Why
- 팀 논의(2026-11-01): 상담원 챗봇이 생겼으니 유사 사례는 필요할 때 챗봇에 물으면 된다. 티켓 상세 ② 탭의 "비슷한 해결사례" 블록은 뺀다.
- 목업의 상담원 도우미는 ELLO 캐릭터(끌어서 옮기는 단추, 캐릭터가 붙은 창·말풍선)다. 저장소는 글자 "도우미" 단추다.

## What Changes
- 화면만 바꾼다. 서버·API·DB 변경 없음(유사 사례 API와 접수 이력 화면은 그대로 둔다).
- ② 탭에서 "비슷한 해결사례" 블록과 [접수 이력에서 보기] 단추를 뺀다.
- 도우미 단추를 ELLO 캐릭터 원형 단추로, 창 이름을 "ELLO 상담원 도우미"로. 창 머리·답 말풍선에 캐릭터, 빈 대화에 큰 캐릭터. 단추·창은 끌어서 옮기고(두 번 누르면 제자리) 위치는 이 브라우저에 기억.
- 답은 지금처럼 서버 근거 검색(SCR-10) 결과를 쓴다. 목업의 규칙 기반 응답은 쓰지 않는다.

## 시험
SCR-03-AC-19를 "블록 없음"으로 바꾸고 SCR-09 연결 시험을 지운다. SCR-10 시험 통과.
