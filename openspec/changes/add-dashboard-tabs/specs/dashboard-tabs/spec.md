## ADDED Requirements

### Requirement: 운영 대시보드에 AI·제품·고객 집계를 보인다 (FR-초안-05)
운영 대시보드의 AI·제품·고객 탭은 서비스 기록(메시지, 자체 검사, 하위 문의, 경고)을 세기만 해서 보여야 하고, 정답지(gold) 열은 읽지 않아야 한다(MUST). 승인 없이 보낸 메시지를 세는 항목은 없어야 한다(MUST).

#### Scenario: 제품 탭 합계
- **GIVEN** 미해결 360건을 적재하고 기준 시각 = 스냅샷
- **WHEN** 제품 탭을 연다
- **THEN** 제품별 미해결 수의 합("제품 미상" 줄 포함)이 360이다

#### Scenario: AI 탭 세기
- **GIVEN** 시스템 초안 2건 중 1건을 상담원이 고쳐 발송한 상태
- **WHEN** AI 탭을 연다
- **THEN** 초안 2, 발송 1, 고쳐서 보낸 비율 100%가 보인다
