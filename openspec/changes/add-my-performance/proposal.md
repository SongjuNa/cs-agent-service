# Proposal: 내 실적 (add-my-performance)

## Why
최신 목업의 나의 업무 현황 아래에는 "내 실적"(오늘 처리, 최근 며칠 처리·하루 평균, 기한 충족, 날짜별 막대)이 있다. 목업의 막대는 부서 접수량에 내 몫을 곱한 **샘플**이었다. 저장소에는 오늘 처리한 건수만 있고(GAP.md C #8 "축소"), 해결·종료 이력을 변경 `add-dashboard-history`로 적재해 실제 값으로 만들 수 있게 되었다. 팀 합의(2026-10-31)로 목업이 최신 기준이다.

## What Changes
- **새 API 1개** `GET /me/performance?days=&as_of=`(머리 `X-Agent-Id`, 읽기만, **새 열·표 없음**). 상담원이 최근 days일(기본 7, 최대 90) 동안 한 처리를 날짜별로(오래된 날부터, 빈 날 0), 내 담당이고 접수일이 기간 안인 문의의 기한 충족을 돌려준다. 상담원을 비우면 400.
  - **처리 = 내가 보낸 정보 요청·답변(발송) + 내가 한 이관 + 내가 한 우선순위 조정.** 나의 업무 현황의 "오늘 처리한 건수"(`db/workload.py`)와 같은 정의라 오늘 숫자가 같다.
  - 기한 충족은 **기간 접수·내 담당** 기준이다(목업은 "미해결 기준"). 해결·종료 이력이 있어 더 의미 있는 기간 기준으로 했다.
- 화면: 나의 업무 현황 맨 아래 "내 실적" 카드. 기간 7일·14일·30일, 날짜별 막대. 상담원을 고른 "내 담당" 보기에만 보인다.

## 범위 밖
부서 전체 실적, 상담원 간 비교, 처리 시간(응답이 걸린 시간) 분포.
