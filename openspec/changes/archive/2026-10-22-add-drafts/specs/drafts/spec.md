# Spec Delta: drafts

## Purpose

막는 정보가 있으면 정보 요청 초안(FR-015)을, 없고 근거가 있으면 답변 초안(FR-021)을 만들고, 인용·숫자를 코드로 대조하고(기술 명세서 v1.4 §3-4), 한국어 대역(FR-039)을 붙인다. 고객에게 가는 글은 모두 DRAFT다(CLAUDE.md 규칙 3).

## ADDED Requirements

### Requirement: 막는 정보가 있으면 정보 요청 초안을 만든다 (FR-015)
초안 단계는 막는 항목(missing_blocking_info)이 있을 때만 정보 요청 초안을 고객 언어(language)의 메일 한 통으로 만들어야 한다(MUST)(근거: 명세서 FR-015 처리 1·5). 막는 항목은 "필수", 나머지 빠진 항목은 "가능하면"으로 나누고 항목마다 영어 라벨을 괄호로 함께 적게 해야 한다(MUST)(근거: FR-015 처리 2·3). 막는 항목 라벨이 본문에 없으면 1회 다시 만들고, 그래도 없으면 빠진 라벨을 본문 끝에 목록으로 덧붙여야 한다(MUST)(근거: FR-015 예외 2행). 언어 모델이 두 번 실패하면 영어 고정 문구 F-1로 만들고 "자동 번역 실패"를 표시해야 한다(MUST)(근거: FR-015 예외 1행, 에이전트 설계서 부록 A F-1). 결과는 종류 INFO_REQUEST, 상태 DRAFT여야 한다(MUST)(근거: FR-015 처리 6, CLAUDE.md 규칙 3).

#### Scenario: AC-015-1 전화 문의도 메일 모양 정보 요청
- **GIVEN** CSV1-000017 (막는 항목 serial_no, 언어 en, 전화)
- **WHEN** 초안을 만든다
- **THEN** 영어 INFO_REQUEST 초안이 생기고 본문에 "Serial number (nameplate)"가 있다

#### Scenario: AC-015-2 고객 언어로 쓰고 영어 라벨을 병기한다
- **GIVEN** CSV1-003578 (이탈리아 고객, 본문은 영어 메모, 막는 항목 있음)
- **WHEN** 초안을 만든다
- **THEN** 초안 언어가 이탈리아어(it)이고 막는 항목의 영어 라벨이 본문에 있다

#### Scenario: AC-015-3 막는 항목이 없으면 정보 요청을 만들지 않는다
- **GIVEN** 막는 항목이 없는 CSV1-000004
- **WHEN** 흐름이 돈다
- **THEN** INFO_REQUEST 초안이 없다

### Requirement: 근거와 조회값만으로 답변 초안을 만든다 (FR-021)
초안 단계는 막는 항목이 없고 근거 후보가 있을 때 근거 절 본문, 조회값, 제공 항목, 유형별 뼈대를 넣어 고객 언어 답변 초안을 만들어야 한다(MUST)(근거: 명세서 FR-021 처리 1·3·4). 빠진 항목만 있으면 끝에 "가능하면 보내 주실 것" 한 줄을 넣게 해야 한다(MUST)(근거: FR-021 처리 1). 근거 후보가 없으면 초안을 만들지 않고 "근거 없음 — 상담원 작성 필요"를 표시해야 한다(MUST)(근거: FR-021 처리 2). 언어 모델이 두 번 실패하면 초안 없이 "초안 생성 실패. 다시 시도"를 표시해야 한다(MUST)(근거: FR-021 예외 1행). 결과는 종류 FINAL_REPLY, 상태 DRAFT여야 한다(MUST)(근거: FR-021 처리 6).

#### Scenario: AC-021-1 견적 답변 초안
- **GIVEN** CSV1-000004
- **WHEN** 초안을 만든다
- **THEN** 프랑스어이고 "520.00 USD"(또는 같은 값의 표기), "4 semaines"(또는 동등 표현), 유효기간 30일이 있으며 숫자 출처가 product_master.csv이고, 끝에 영업 담당이 정확한 견적을 따로 안내한다는 문장이 있다

#### Scenario: AC-021-2 펌웨어 이미 최신
- **GIVEN** CSV1-000008 (아랍어, 접수 시점 최신 3.40)
- **WHEN** 초안을 만든다
- **THEN** "이미 최신" 취지의 아랍어 문장과 RN-ESS-BMS-V3 인용이 있고 3.50은 나오지 않는다

#### Scenario: AC-021-3 근거가 없으면 초안을 만들지 않는다
- **GIVEN** 근거 후보가 비어 있는 티켓
- **WHEN** 흐름이 돈다
- **THEN** 답변 초안이 없고 "근거 없음 — 상담원 작성 필요"가 표시된다

### Requirement: 답변 초안은 사용한 조회값과 길이를 지킨다 (FR-021 출력·예외 4행)
답변 초안은 본문에 값이 나온 조회값을 출처와 함께 사용한 조회값 목록으로 남겨야 한다(MUST)(근거: FR-021 출력). 본문이 1,500자를 넘으면 1회 다시 만들고, 그래도 길면 초안을 두고 "초안 길이 초과"를 표시해야 한다(MUST)(근거: FR-021 예외 4행).

#### Scenario: AC-021-1 숫자 출처를 남긴다
- **GIVEN** CSV1-000004의 답변 초안
- **WHEN** 사용한 조회값 목록을 본다
- **THEN** 단가의 출처가 product_master.csv다

### Requirement: 초안의 인용과 숫자를 코드로 대조한다 (FR-021 처리 5)
자체 대조는 초안의 인용 `(DOC_ID §절)`이 모두 근거 후보 안에 있는지, 초안의 숫자와 날짜가 모두 허용 목록(조회값, 제공 항목 중 수량·버전·날짜, 인용 절 번호, 근거 절 본문의 숫자) 안에 있는지 검사해야 한다(MUST)(근거: 기술 명세서 §3-4 1·2번, AC-017-5). 어긋나면 1회 다시 만들고, 다시 어긋나면 초안을 두고 어긋난 자리를 남겨야 한다(MUST)(근거: FR-021 처리 5·예외 2행, §3-4 4번). 이 검사는 언어 모델을 부르지 않아야 한다(MUST)(근거: §3-4 "LLM 아님, 코드").

#### Scenario: AC-017-5 허용 목록 밖 숫자와 근거 밖 인용을 잡는다
- **GIVEN** 근거 후보에 없는 절을 인용하고 조회값에 없는 숫자를 쓴 초안 (시험 입력은 구현 선택)
- **WHEN** 대조한다
- **THEN** 그 인용과 숫자가 어긋난 자리로 나오고, 1회 다시 만든 뒤에도 같으면 초안이 남고 어긋난 자리가 기록된다

### Requirement: 초안의 가린 값은 되돌리지 않는다 (AC-038-4)
초안과 대역에 든 가린 값(COMPANY_… 등)은 원래 이름으로 되돌리지 않고 그대로 두어야 한다(MUST)(근거: 명세서 AC-038-4, CLAUDE.md 규칙 2).

#### Scenario: AC-038-4 고객사 이름은 가린 값 그대로
- **GIVEN** 답변 초안에 고객사 이름이 들어가는 경우
- **WHEN** 초안을 본다
- **THEN** "COMPANY_4975_0183" 같은 가린 값 그대로이고 되돌린 이름이 없다

### Requirement: 초안마다 한국어 대역을 붙인다 (FR-039)
대역 단계는 초안 언어가 대역 언어(ko)와 다를 때 대역을 만들고, 대역은 초안 본문과 따로 두어야 한다(MUST)(근거: 명세서 FR-039 처리 1·2). 대역에는 만든 시각을 남겨야 한다(MUST)(근거: FR-039 출력, 기술 명세서 §2-2 Q13). 인용과 숫자는 원문 그대로 두게 하고, 원문과 대역의 인용·숫자 집합이 다르면 1회 다시 요청하고 그래도 다르면 "인용·숫자 확인"을 표시해야 한다(MUST)(근거: FR-039 처리 3, 기술 명세서 §3-2 L7). 번역이 실패하면 대역 없이 "대역 없음(번역 실패)"을 표시하고 초안은 그대로 두어야 한다(MUST)(근거: FR-039 예외 1행).

#### Scenario: AC-039-1 대역의 숫자와 인용은 원문과 같다
- **GIVEN** CSV1-000004의 프랑스어 답변 초안
- **WHEN** 대역을 만든다(화면에서 여는 부분은 9번 변경)
- **THEN** 한국어 대역이 있고 "520.00 USD"(초안에 쓴 표기)와 인용 표시가 원문과 같다

#### Scenario: AC-039-3 번역이 실패해도 초안은 남는다
- **GIVEN** 번역이 실패하는 상태
- **WHEN** 초안이 만들어진다
- **THEN** "대역 없음(번역 실패)"이 표시되고 초안은 DRAFT로 그대로 있다
