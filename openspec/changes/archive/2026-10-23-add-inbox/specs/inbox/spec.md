# Spec Delta: inbox

## Purpose

상담원이 고른 부서의 끝나지 않은 하위 문의를 급한 순서로 보고 골라 상세로 간다(명세서 v1.5 FR-029).

## ADDED Requirements

### Requirement: 부서 접수함 목록 (FR-029)
접수함은 고른 부서가 담당하거나 이관받은 하위 문의를 한 줄씩, 종료 포함이 꺼져 있으면 끝나지 않은 것만 보여야 하며, 경고 있는 줄을 위로 그 안에서 해결 남은 시간 오름차순으로 정렬해야 한다(MUST)(근거: FR-029 처리 1~3, FR-027 처리 5). 필터를 함께 걸 수 있어야 하고 복합 문의는 하위 문의마다 "복합 n건 중 k"로 보여야 한다(MUST)(근거: FR-029 처리 4·5).

#### Scenario: AC-029-1 스냅샷 TS_LV
- **GIVEN** 미해결 360건을 적재하고 기준 시각 = 스냅샷
- **WHEN** 부서 TS_LV를 고른다
- **THEN** 67건이 보이고 맨 위 줄은 경고가 있으며 남은 시간이 가장 적다

#### Scenario: AC-029-2 정보 요청 필요 필터
- **GIVEN** 같은 상태
- **WHEN** "정보 요청 필요" 필터를 켠다
- **THEN** missing_blocking_info가 비어 있지 않은 줄만 남는다

#### Scenario: AC-029-3 복합 문의 줄
- **GIVEN** CSV1-000008을 접수해 복합 문의가 된 상태
- **WHEN** 두 하위 문의의 담당 부서 접수함을 각각 본다
- **THEN** 각 접수함에 그 하위 문의 한 줄이 "FW_UPDATE (복합 2건 중 1)", "MANUAL (복합 2건 중 2)"처럼 보인다(같은 부서면 한 접수함에 두 줄)

#### Scenario: AC-029-4 상세 열기
- **GIVEN** 접수함의 한 줄
- **WHEN** 누른다
- **THEN** 그 티켓의 상세 화면이 열린다

#### Scenario: AC-029-5 종료 제외
- **GIVEN** 종료 포함 스위치가 꺼진 상태
- **WHEN** 목록을 본다
- **THEN** RESOLVED·CLOSED 줄이 없다

### Requirement: 부서 미선택 (FR-029 예외)
부서를 고르지 않으면 목록을 비우고 "부서를 선택하세요"를 보여야 한다(MUST)(근거: FR-029 예외 1행).

#### Scenario: 부서 없이 열기
- **GIVEN** 부서를 고르지 않은 상태
- **WHEN** 접수함을 연다
- **THEN** 빈 목록과 "부서를 선택하세요"가 보인다

### Requirement: 빈 목록·SLA 미정·읽기 실패 (FR-029 예외)
고른 부서에 줄이 없으면 "처리할 티켓이 없습니다"를, SLA 목표가 없는 줄은 "SLA 미정"으로 맨 아래에, 목록 읽기에 실패하면 이전 목록을 흐리게 두고 다시 읽기를 안내해야 한다(MUST)(근거: FR-029 예외 2·3·4행).

#### Scenario: 빈 목록
- **GIVEN** 고른 부서에 끝나지 않은 하위 문의가 없다
- **WHEN** 접수함을 연다
- **THEN** 빈 목록과 "처리할 티켓이 없습니다"가 보인다

#### Scenario: SLA 미정 맨 아래
- **GIVEN** 해결 목표가 없는 하위 문의가 있다
- **WHEN** 기본 정렬로 본다
- **THEN** 그 줄은 남은 시간 칸이 "SLA 미정"이고 맨 아래에 있다

#### Scenario: 목록 읽기 실패
- **GIVEN** 목록이 한 번 보인 상태
- **WHEN** 다시 읽기가 실패한다
- **THEN** 이전 목록이 흐리게 남고 "목록을 불러오지 못함. 새로고침"이 보인다
