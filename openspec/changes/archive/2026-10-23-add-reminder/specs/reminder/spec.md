# Spec Delta: reminder

## Purpose

정보 요청 뒤 126시간 동안 회신이 없으면 고정 문안 리마인드를 시스템이 한 번 자동 발송한다(명세서 v1.5 FR-023, D29).

## ADDED Requirements

### Requirement: 126시간 회신 요청 리마인드 (FR-023)
WAITING_CUSTOMER이고 마지막 정보 요청 발송 뒤 126시간이 지나도록 고객 회신이 없으면, 언어 모델 없이 고정 문안과 정보 요청에 쓴 빠진 항목 라벨로 리마인드를 만들어 시스템이 바로 발송해야 한다(MUST)(근거: FR-023 처리 1~3, 기술 명세서 §6-4 주기 점검 2). 상태와 1차 응답 시각은 바꾸지 않아야 하고, 문의당 한 번만 보내야 한다(MUST)(근거: FR-023 처리 4). 문안에는 SLA 목표 시간이나 완료 예정 시각을 넣지 않아야 한다(MUST)(근거: FR-023 처리 2, AC-023-8). 고객 언어 템플릿이 없으면 영어로 보내고 "영어로 발송"을 알려야 한다(MUST)(근거: FR-023 예외 1행, 저장 위치는 C-78).

#### Scenario: AC-023-5 영어 리마인드 자동 발송
- **GIVEN** CSV1-000017이 serial_no 정보 요청 뒤 WAITING_CUSTOMER
- **WHEN** 126시간이 지나 점검한다
- **THEN** 영어 리마인드가 보낸 쪽 SYSTEM으로 발송되고 상태는 WAITING_CUSTOMER 그대로다

#### Scenario: AC-023-6 168시간 종료
- **GIVEN** 리마인드 뒤 42시간이 더 지난 168시간
- **WHEN** 점검한다
- **THEN** CLOSED_NO_RESPONSE로 닫힌다

#### Scenario: AC-023-7 회신이 먼저 오면 없음
- **GIVEN** 120시간에 고객 회신 입력
- **WHEN** 126시간이 되어 점검한다
- **THEN** 리마인드가 만들어지지 않는다

#### Scenario: AC-023-8 기한 없는 문안
- **GIVEN** 리마인드 본문
- **WHEN** 검사한다
- **THEN** SLA 목표 시간이나 완료 예정 시각이 없다

#### Scenario: 한 번만
- **GIVEN** 리마인드를 이미 보낸 문의
- **WHEN** 다시 점검한다
- **THEN** 새 리마인드가 생기지 않는다

#### Scenario: 템플릿 없는 언어
- **GIVEN** 고객 언어가 fr인 문의(fr 템플릿 없음)
- **WHEN** 126시간 뒤 점검한다
- **THEN** 영어로 발송하고 "영어로 발송"을 돌려준다

#### Scenario: AC-035-6 보낸 쪽 (앞부분)
- **GIVEN** 자동 발송된 리마인드
- **WHEN** 메시지를 조회한다
- **THEN** 리마인드 SENT 행의 보낸 쪽은 SYSTEM이고 그 밖의 발송 행은 상담원이다
