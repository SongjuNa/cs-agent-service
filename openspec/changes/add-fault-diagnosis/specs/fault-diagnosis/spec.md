# Spec Delta: fault-diagnosis

## Purpose

고장 계열 문의에서 고장 사전으로 원인·조치 후보("진단 후보")를 찾아 상담원에게 참고 자료로 보여 준다(명세서 v1.5 FR-018).

## ADDED Requirements

### Requirement: 고장 진단 후보 (FR-018)
시스템은 유형이 DEFECT·INSTALL·WARRANTY인 하위 문의에서만, 에러 코드가 있으면 고장 사전의 같은 제품군·같은 에러 코드 행을 "정확 일치"로 찾고, 없거나 에러 코드가 없으면 같은 제품군 행 중 증상 문장이 가까운 것을 "증상 검색"으로 찾아 진단 후보(원인, 조치, 현장 출동·교체 필요, 출처, 찾은 방법, 점수)를 남겨야 하며, 진단 후보를 답변 초안의 입력에 넣어서는 안 된다(MUST)(근거: FR-018 처리 1~5).

#### Scenario: AC-018-1 정확 일치
- **GIVEN** error_code_reported P.06이 고장 사전에 있는 고장 문의 CSV1-000007(제품 PLC-XGB-XBM-DR16S)
- **WHEN** 진단하면
- **THEN** 같은 제품군(PLC)·에러 코드의 항목 FLT-028이 찾은 방법 "정확 일치"(EXACT)로 진단 후보 1순위에 있다

#### Scenario: AC-018-2 증상 검색
- **GIVEN** 에러 코드가 없는 고장 문의 CSV1-000055(제품 HMI-XGT-iXP90)
- **WHEN** 진단하면
- **THEN** 같은 제품군(HMI) 항목만 후보에 오르고 찾은 방법이 "증상 검색"(SYMPTOM)으로 기록된다

#### Scenario: AC-018-3 진단하지 않는 유형
- **GIVEN** CSV1-000004(QUOTE)
- **WHEN** 처리 흐름이 돌면
- **THEN** 진단 단계(Q8a)가 실행되지 않는다

#### Scenario: AC-018-4 초안 입력에 없음
- **GIVEN** 진단 후보가 있는 문의
- **WHEN** 답변 초안 단계의 입력 기록(FR-036)을 보면
- **THEN** 진단 후보가 들어 있지 않다

#### Scenario: AC-018-5 이관 표시 일치율
- **GIVEN** 고장 문의 중 에러 코드로 진단되는 행(팀 정답지 대신 tickets.csv, C-137)
- **WHEN** 진단 후보 1순위의 현장 출동·교체 필요 표시를 정답의 이관 여부와 이관 사유와 비교하면
- **THEN** 일치율을 보고한다

#### Scenario: AC-018-2 예외(FR-018 예외 처리 표)
- **GIVEN** 제품군 항목이 없거나, 에러 코드가 미등록이거나, 점수가 모두 기준 미만이거나, 검색이 실패한 고장 문의
- **WHEN** 진단하면
- **THEN** 각각 "고장 사전에 해당 제품군 없음" / "에러 코드 미등록" 표시 뒤 증상 검색 / "관련성 낮음" / "진단 실패"가 보이고 처리 흐름은 계속된다

### Requirement: 진단 후보 표시 (FR-018)
티켓 상세는 고장 계열 하위 문의 구역에 진단 후보(1순위 크게, 2·3순위 접힘, 참고용 표시)와 근거 줄 "고장 진단"을 보여야 한다(MUST)(근거: FR-018 출력, 화면 정의서 v1 SCR-03 C-08, FR-024 입력).

#### Scenario: AC-024-1 상세의 고장 진단 줄
- **GIVEN** 처리가 끝난 CSV1-000017(고장 문의, 에러 코드 없음)
- **WHEN** 티켓 상세를 열면
- **THEN** 근거 영역에 "고장 진단" 줄(진단 후보, 없으면 "없음(사유)")이 보인다

#### Scenario: AC-018-1 상세의 진단 후보
- **GIVEN** CSV1-000007을 처리했다
- **WHEN** 티켓 상세를 열면
- **THEN** 진단 후보 FLT-028(정확 일치, 교체 필요)이 "참고용, 초안에는 쓰지 않음"과 함께 보인다
