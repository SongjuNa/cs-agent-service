# Proposal: 나의 업무 현황 — 새 문의·지금 처리할 건 (add-mywork-now)

## Why
최신 목업의 나의 업무 현황은 "새 문의" 숫자, 내가 지금 처리할 문의 목록, 가장 급한 내 문의를 보인다. 저장소 화면은 타일 4개와 탭 표뿐이다. 접수함 변경(add-inbox-turn-depth)으로 서버가 이미 내 담당·내 차례·다음 행동·검토 모드를 주므로, **서버 변경 없이** 만들 수 있다. 팀 합의(2026-10-31)로 목업이 최신 기준이다.

## What Changes
- 화면만 바꾼다(서버·API·DB 변경 없음). 접수함 API(`GET /tickets`의 `assignee`·`turn`·`me`, counts)를 쓴다.
- 타일 ⑤ "새 문의"(counts.new), "지금 처리할 건"(turn=ME 앞 8줄), "가장 급한 내 문의"를 더한다. 기존 타일 4개·탭·오늘 처리한 건수는 그대로.

## 범위 밖 (팀 확인 필요, 이 변경에서 하지 않는다)
- **AI 자동 처리 카드, 사후 검수**: 자동 발송은 규칙 3·D32와 충돌한다. 구현하지 않는다.
- **내 실적**(최근 7일 처리 건수, 하루 평균, 1차 응답 충족률): 과거 기록 API가 없다.
- **새로 온 건 / 1차 응답 아직 안 보낸 건** 별도 카드: 목록은 접수함의 상태·경고 필터로 대신할 수 있다(다음 변경).

## Impact
`features/mywork/MyWorkPage.tsx`, `mywork.css`, 화면 명세 SCR-04(타일 ⑤·NOW·TOP, AC-9), 추적표, 시험 `scr-04.spec.ts`.
