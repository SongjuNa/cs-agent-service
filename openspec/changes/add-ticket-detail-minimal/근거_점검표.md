# 근거 점검표: add-ticket-detail-minimal

## 1. 기계 점검 (`scripts/check_sources.py`)

- **없는 이름 4건은 모두 잘못 잡은 것이다.**
  - `svc.transition`은 schema.sql의 함수다(824행, "접수 이력(INTAKE)도 이 함수로").
  - `svc.ticket_new_no`는 시퀀스다(461행, START 4001).
  - `CSV1-004001`은 새 접수 번호의 첫 값이다(459행 주석).
- **근거 꼬리표가 없는 줄 13건**은 표 머리나 위 줄에 근거가 있는 표 행·하위 목록이다. 예를 들어 check_type 표는 머리말에 "테이블 정의서 v1.3 self_check 주석"이라고 적혀 있다.
