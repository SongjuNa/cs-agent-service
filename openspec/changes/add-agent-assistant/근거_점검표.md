# 근거 점검표: add-agent-assistant

제안서에 쓴 주장마다 **무엇을 보고 썼는지**와 **아직 확인하지 못한 것**을 적는다. 저장소 `skkuls-final-team/CS-agent-service` main(2026-10-30)을 읽기 전용으로 내려받아 본 것이다.

## 읽고 쓴 것 (확인함)

| 주장 | 본 곳 |
|---|---|
| 문서 절 검색이 `ref.doc_chunk` 임베딩 + 정확 문자열 가산점(0.2) + 상위 5개 | `backend/app/retrieval/search.py` |
| 그 검색은 티켓 범위(정책 + 제품군 FAQ + 제품 문서)를 전제로 한다 | 같은 파일 `_scope` |
| 모든 모델 호출이 `generate_json`을 지나고 보내기 직전 가린다 | `backend/app/llm/client.py`, `llm/inputs.py` |
| 연락처 열이 입력에 있으면 거부한다 | `llm/inputs.py` |
| 프롬프트는 `prompts/l*_v*.md`, 데이터를 태그로 감싼다 | `prompts/l8_verify_v1.md` |
| 새 표·열을 만들지 않는다, 모델은 한 곳에서만 부른다, 고객 메시지는 DRAFT만 | `CLAUDE.md` 규칙 2·3·4 |
| 여유 시 기능은 FR-019·FR-034만, 나머지는 만들지 않는다 | `openspec/config.yaml` |
| 챗봇 관리 메뉴는 목업 화면(`MOCK_ONLY`), API 경로에 chat·assist 없음 | `frontend/src/App.tsx`, `openapi.json` |
| 응답 모델·화면 구조·검색 기록 저장 안 함의 선례 | `openspec/changes/add-case-search/` |
| 화면 규칙(부품은 `src/ui/`, 토큰, TanStack Query, 오류 처리) | `frontend/CLAUDE.md`, `docs/frontend/principles.md` |

## 지어내지 않은 것
- 목업 ELLO의 규칙 기반 응답은 이 제안서의 근거로 쓰지 않았다. 목업은 **화면 모양**의 기준이고, 답의 내용·출처 규칙은 저장소의 기존 방식을 따랐다.
- 질문 수·응답 시간 같은 성능 숫자는 적지 않았다(측정한 적 없음).
