## ADDED Requirements

### Requirement: 상담원이 문서 근거로 질문하고 출처가 붙은 답을 받는다 (FR-초안-07)
상담원은 질문을 보내 문서 절 안의 내용으로 만든 한국어 답과 그 출처(문서 번호, 절 번호, 제목)를 받을 수 있어야 한다(MUST). 답은 찾은 절의 내용 안에서만 만들어야 하고, 근거가 없으면 찾지 못했다고 답해야 한다(MUST). 출처 없는 답은 돌려주지 않아야 한다(MUST).

#### Scenario: 근거 있는 질문
- **GIVEN** 문서 색인을 만든 상태
- **WHEN** 색인에 있는 오류 코드로 질문한다
- **THEN** `found`가 참이고 `sources`에 그 코드가 든 절이 있으며 모든 `chunk_id`가 존재한다

#### Scenario: 근거 없는 질문
- **GIVEN** 문서에 없는 주제
- **WHEN** 질문한다
- **THEN** `found`가 거짓이고 `sources`는 비어 있으며 답은 "찾지 못했습니다"로 시작한다

#### Scenario: 위조된 출처 번호
- **GIVEN** 언어 모델이 보낸 출처 밖의 번호를 `used_sources`에 적은 응답
- **WHEN** 답을 정리한다
- **THEN** 그 번호는 버려지고 남은 출처가 없으면 `found`가 거짓이 된다

### Requirement: 질문은 가려서 보내고 저장하지 않는다 (CLAUDE.md 규칙 2·4)
질문과 이어 묻기 대화는 임베딩과 언어 모델에 보내기 직전에 개인정보를 가려야 한다(MUST). 서버는 질문, 답, 대화를 표에 저장하지 않아야 한다(MUST).

#### Scenario: 질문 속 이메일
- **GIVEN** 질문에 이메일 주소가 든 경우
- **WHEN** 질문한다
- **THEN** 임베딩과 모델에 간 글에는 가려진 값이 들어 있다

#### Scenario: 저장 없음
- **GIVEN** 질문 전의 표 행 수
- **WHEN** 질문하고 답을 받는다
- **THEN** 표 행 수가 같다

### Requirement: 답은 상담원 참고용이다 (CLAUDE.md 규칙 3)
이 답은 화면에만 보여야 하고, 초안·메시지·고객 발송에 쓰이지 않아야 한다(MUST).

#### Scenario: 발송 경로 없음
- **GIVEN** 도우미의 답
- **WHEN** 상담원이 화면에서 답을 본다
- **THEN** 그 답을 초안으로 만들거나 고객에게 보내는 동작이 없다

### Requirement: 실패해도 찾은 문서는 보여 준다
언어 모델이 실패하면 답 없이 찾은 절 목록과 안내 문구를 돌려줘야 한다(MUST). 임베딩이 실패하면 `found`를 거짓으로 하고 안내 문구를 돌려줘야 한다(MUST).

#### Scenario: 모델 실패
- **GIVEN** 언어 모델이 두 번 실패하는 상태
- **WHEN** 질문한다
- **THEN** 답은 비어 있고 `sources`에 찾은 절이 있으며 `notes`에 "답을 만들지 못했습니다. 아래 문서를 직접 확인하세요"가 있다

### Requirement: 입력을 검증한다
빈 질문이나 500자를 넘는 질문은 거부해야 한다(MUST).

#### Scenario: 빈 질문
- **GIVEN** 질문이 비어 있는 상태
- **WHEN** 보낸다
- **THEN** 400 "질문을 입력하세요"가 온다

#### Scenario: 긴 질문
- **GIVEN** 501자 질문
- **WHEN** 보낸다
- **THEN** 400 "질문은 500자 이하로 입력하세요"가 온다
