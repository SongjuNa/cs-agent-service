# Proposal: 접수함 표 모양을 최신 목업에 맞춤 (add-inbox-table-look)

## Why
최신 목업과 나란히 보면(2026-11-01) 접수함 표의 상태·남은 시간이 글자뿐이고, 급한 행 표시와 왼쪽 메뉴의 "새 N"이 없다.

## What Changes
화면만 바꾼다. 서버·API·DB 변경 없음.
- 처리 상태: 색 칩. 해결 기한까지: "6일 10시간 초과"·"2시간 남음" 말과 색 칩(초과 붉게, 임박 노랗게, 여유 초록). 시간 숫자는 칩에 마우스를 올리면 보인다.
- 지금 처리할 문의 중 P1이거나 해결 기한이 지난 행은 왼쪽에 붉은 줄.
- 왼쪽 메뉴 접수함 옆에 "새 N"(새 문의 수)과 전체 수.
- 접수 시각은 "09-17 13:23"으로 줄이고(전체는 마우스 올리면), 표가 화면 폭 안에 들어오게 칸 폭을 줄인다.

## 하지 않는 것
- 목업의 "초안 있음" 문서 아이콘 열, 고객사 이름 표기(DB 데이터가 다르다), "문의 접수" 버튼 제거는 이번에 하지 않는다.
