# Proposal: ELLO 질문 후보 버튼 (add-ello-suggestions)

## Why
최신 목업의 상담원 도우미(ELLO)는 첫 화면에 미리 만든 질문 후보가 있고 누르면 바로 묻는다. 저장소 도우미(add-ello-assistant)에는 안내 글만 있고 후보가 없다(2026-11-01 사용자 지적).

## What Changes
화면만 바꾼다. 서버·API·DB 변경 없음(기존 `POST /assist/ask`의 `product_code`를 쓴다).
- 빈 대화에 후보 버튼 4개: E.OC 오류 원인과 조치 / MCCB 400AF 사양 / 보증 기간과 RMA 절차 / 반품 정책.
- 문의 상세에서 열면 "지금은 {번호}를 보고 있어"를 보이고, 그 문의의 오류 코드·제품·유형에 맞춰 후보를 바꾸며, 질문에 제품 코드를 실어 보낸다.

## 하지 않는 것
- 목업의 "이 제품의 비슷한 문의" 후보는 넣지 않았다. 서버 도우미는 문서 절만 근거로 답해서(add-agent-assistant) 해결사례를 찾지 못한다. "유사 사례는 챗봇으로 물어본다"는 팀 결정(2026-11-01)을 지키려면 서버 도우미가 해결사례 검색을 근거로 쓰도록 바꿔야 한다(별도 변경).
