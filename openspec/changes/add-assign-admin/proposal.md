# Proposal: 문의 배정 관리 화면과 일괄 우선순위 조정 (add-assign-admin)

## Why
최신 목업에는 관리용 "문의 배정 관리" 화면(부서·담당 상담원·사유로 거르고 담당을 바꿈)과 접수함의 "우선순위 일괄 조정"이 있다(GAP.md F, A-1 #12). 담당 변경 API는 변경 `add-reassign`에서 만들었고 우선순위 조정은 단건 API(FR-028)가 이미 있다. 팀 합의(2026-10-31)로 목업이 최신 기준이다.

## What Changes
- **서버 변경 없음, 새 열·표 없음.** 접수함 목록 API와 담당 변경 API, 단건 우선순위 조정 API를 조합한다.
- 새 화면 SCR-11 문의 배정 관리(`/admin/assign`, 왼쪽 메뉴 "대시보드" 묶음): 거르기 4종, 줄마다 담당 선택, 일괄 재배정, [필터된 n건 모두 선택](200건까지), 쪽당 15건.
- 접수함 선택 막대에 [우선순위 조정]: 새 우선순위·사유 분류·사유를 넣으면 건마다 미리 보기(GET)로 위반 여부를 읽고 한 건씩 차례로 조정(POST). 이미 그 우선순위인 건·계산하지 못한 건은 건너뛰고, 일부 실패해도 나머지는 적용하며 건수를 알린다. 한 번에 50건까지.

## 범위 밖
- 서버 한 번 호출로 일괄 조정(건마다 부르는 대신): 건수가 늘면 필요하다. 지금은 50건 제한.
- 부서 전체 보기, "이관 장기" 사유(서버에 값 없음), 담당 변경 이력 화면.

## Impact
`features/assign/`, `features/inbox/BulkAdjustPopup.tsx`·`InboxPage.tsx`, `App.tsx`·`AppShell.tsx`(메뉴), 화면 명세 SCR-11·SCR-02, 시험 `scr-11.spec.ts`(4개)·SCR-02-AC-14.
