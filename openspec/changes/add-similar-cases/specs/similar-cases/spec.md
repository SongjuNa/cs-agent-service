## ADDED Requirements

### Requirement: 고장 계열 문의에서 비슷한 해결사례를 찾는다 (FR-019)
유형이 DEFECT·INSTALL·WARRANTY·FW_UPDATE·RETURN인 하위 문의에서만 해결사례를 찾아 비슷한 순으로 3건까지 실행 기록과 상세 응답에 남겨야 한다(MUST). 팀 정답지 문의에서 나온 사례와 그 문의 자신의 사례는 결과에 없어야 한다(MUST). 찾지 못하거나 실패해도 처리 흐름은 계속되어야 한다(MUST).

#### Scenario: AC-019-1 고장 문의의 사례
- **GIVEN** CSV1-000017(DEFECT, ACB-AS-2000)을 불러와 접수한 상태
- **WHEN** 상세를 연다
- **THEN** 비슷한 해결사례가 3건 이하로 보이고, 팀 정답지 문의의 사례와 자기 사례 RC-0006이 없다

#### Scenario: AC-019-2 견적 문의
- **GIVEN** CSV1-000004(QUOTE)
- **WHEN** 처리한다
- **THEN** Q8b 단계가 실행 기록에 없다

#### Scenario: 비슷한 사례 없음
- **GIVEN** 같은 제품군 사례가 하나도 없는 고장 문의
- **WHEN** 처리한다
- **THEN** 사례 목록이 비고 "비슷한 사례 없음"이 보이며 흐름은 끝까지 간다

#### Scenario: 사례 검색 실패
- **GIVEN** 임베딩 호출이 실패하는 상태의 고장 문의
- **WHEN** 처리한다
- **THEN** "사례 검색 실패"가 보이고 Q8b 행은 FAILED이며 답변 단계까지 간다

### Requirement: 해결사례는 초안 근거로 쓰지 않는다 (FR-019)
해결사례는 답변 초안 입력에 넣거나 인용하지 않아야 한다(MUST).

#### Scenario: AC-019-3 초안 인용
- **GIVEN** 사례가 보이는 CSV1-000017
- **WHEN** 답변 초안의 인용과 Q10 입력 항목 이름을 본다
- **THEN** 해결사례가 없다
