# Proposal: 상단 오른쪽 도구를 최신 목업에 맞춤 (add-topbar-tools)

## Why
목업 머리 막대 오른쪽에는 종 알림 · 날짜 · 도움말 · 세션 남은 시간(연장) · 설정 · 로그아웃이 있다. 저장소에는 날짜와 종 알림만 있다(2026-11-01 나란히 비교). 앞서 "로그인이 없어 두지 않는다(D23)"던 판단은 "목업이 기준"(2026-10-31 팀 합의)으로 바꾼다.

## What Changes
화면만 바꾼다. 서버·API·DB 변경 없음.
- 도움말: 누르면 작은 창("아직 연결되지 않았습니다", 목업과 같다).
- 세션 남은 시간: 30분에서 줄고 [연장]이 30분으로 되돌린다. 5분 이하면 붉게. 0이 되면 로그아웃한다.
- 설정: 왼쪽 프로필의 "내 정보"(부서·상담원·기준 시각) 창을 연다.
- 로그아웃: 로그인이 없어 고른 부서·상담원을 비우고 나의 업무 현황으로 간다.

## 하지 않는 것
- 로고: ONCE 하나를 유지한다(2026-11-01 사용자 결정). 목업의 "C/S Agent 해외 고객 문의" 글자는 넣지 않았다.
