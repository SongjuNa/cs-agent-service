# Proposal: 초안 형광펜 (add-draft-highlight)

## Why
최신 목업은 답변 초안을 **고치는 중에도** 확인할 곳(근거에 없는 숫자, 검증이 지적한 문장)을 노란 형광펜으로 보인다. 저장소는 읽기 모드에서만 표시(물결·점선 밑줄)하고, [본문 고치기]를 누르면 표시가 사라진다. 팀 합의(2026-10-31)로 목업이 최신 기준이다.

## What Changes
- 화면만 바꾼다(서버·API·DB 변경 없음). 서버는 글자 위치가 아니라 문장(`findings[].quote`)과 값(`detail.bad_numbers`)을 이미 주므로, 화면이 지금 본문에서 찾아 위치를 구한다.
- 공통 부품 `src/ui/MarkedTextarea.tsx`: 입력 칸 뒤에 같은 글자를 투명하게 깔고 구간만 형광펜으로 칠한다(입력 칸이 투명해 글자가 위에 보임).
- 초안 카드의 고치기 칸이 이 부품을 쓴다. 칠할 구간이 있으면 "노란 표시는 확인할 곳입니다" 안내. 고쳐서 문장·값이 사라지면 표시도 사라진다.
- 읽기 모드 표시(물결·점선 밑줄, 인용·조회값 링크)는 그대로.

## 범위 밖
- 부서 회신 값, 번역 못 한 문장 같은 목업의 다른 형광펜 종류(서버에 해당 정보가 없음).
- 한국어 대역 쪽 표시.

## Impact
- 새 `ui/MarkedTextarea.tsx`, `features/ticket/body.tsx`(`markRanges`), `DraftCard.tsx`, 스타일, 화면 명세 SCR-03(AC-25), 시험 `scr-03-head.spec.ts`.
